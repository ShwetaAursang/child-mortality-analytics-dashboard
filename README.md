# Child Mortality Analytics Dashboard

An interactive web-based analytics dashboard developed to analyze global child mortality trends and healthcare datasets through dynamic visualizations and data-driven insights.

## Features

- Interactive data visualizations
- Mortality trend analysis
- Healthcare indicator comparison
- Data filtering and exploration
- Dashboard reporting and insights

## Tech Stack

- Python
- Flask
- MySQL
- D3.js
- HTML5
- CSS3
- JavaScript

## Objectives

- Analyze child mortality patterns across regions
- Identify healthcare-related trends
- Present complex datasets through intuitive visualizations
- Support data-driven decision making

## Applications

- Healthcare Analytics
- Data Visualization
- Public Health Research
- Business Intelligence
